# سینمود - هوش ۲: پیش‌بینی امتیاز فیلم

**نام:** [اسم تو]
**بخش:** هوش ۲ (پیش‌بینی امتیاز فیلم) - چالش چهارشنبه‌های آیولرن

## پروژه چیه؟

مدلی که از روی بودجه، مدت، سال انتشار و ژانر یک فیلم پیش‌بینی می‌کنه که امتیاز «خوب» (۷ یا بیشتر) می‌گیره یا نه. دیتاست: TMDB 5000 Movies.

## فایل‌ها

- `movie_rating.ipynb`: نوت‌بوک اصلی با کد، نمودارها و تحلیل‌ها
- `movie_rating.py`: همون کد به‌صورت اسکریپت پایتون
- `requirements.txt`: کتابخونه‌های لازم

## روش اجرا

1. نصب کتابخونه‌ها:
   `pip install -r requirements.txt`
2. دیتاست `tmdb_5000_movies.csv` باید توی پوشه‌ی `dataset` باشه (دانلود از Kaggle: TMDB 5000 Movie Dataset).
3. اجرا، یکی از دو راه:
   - نوت‌بوک: `jupyter notebook` و باز کردن `movie_rating.ipynb` و Run All
   - اسکریپت: `python movie_rating.py` (نمودارها توی پوشه‌ی `figures` ذخیره می‌شن)

## مراحل کار

1. **پیش‌پردازش:** صفرهای بودجه و مدت به‌عنوان داده‌ی ناموجود در نظر گرفته شدن، فیلم‌های با کمتر از ۵۰ رأی حذف شدن، ژانرها one-hot شدن، و مقادیر گم‌شده با median داده‌ی آموزش پر شدن (بعد از split، برای جلوگیری از data leakage).
2. **هدف:** فیلم «خوب» یعنی `vote_average >= 7` (حدود ۲۳٪ فیلم‌ها).
3. **EDA:** ۴ نمودار (توزیع امتیاز، بودجه در برابر امتیاز، ماتریس همبستگی، نرخ فیلم خوب در هر ژانر).
4. **مدل‌ها:** Logistic Regression، Random Forest و KNN.

## نتایج

| مدل | Accuracy | Precision (good) | Recall (good) | F1 (good) |
|---|---|---|---|---|
| Logistic Regression | 0.746 | 0.473 | 0.727 | 0.573 |
| Random Forest | 0.822 | 0.728 | 0.390 | 0.508 |
| KNN | 0.795 | 0.649 | 0.279 | 0.390 |

چون فقط ۲۳٪ فیلم‌ها «خوب» هستن، Accuracy به‌تنهایی گمراه‌کننده‌ست و به Precision و Recall کلاس «خوب» هم نگاه شده. **Random Forest** انتخاب شد، چون برای پیشنهاد فیلم Precision مهم‌تره: بدترین اتفاق معرفی یه فیلم بد به‌عنوان فیلم خوبه.

## امتیازهای اضافه

- تحلیل اهمیت ویژگی‌ها (Feature Importance) با Random Forest
- جمع‌بندی «چی یه فیلم رو موفق می‌کنه؟» (توی نوت‌بوک)

## محدودیت‌ها

مدل فقط بودجه، مدت، سال و ژانر رو می‌بینه و از کارگردان، بازیگر و داستان خبر نداره، پس دقتش محدوده.
